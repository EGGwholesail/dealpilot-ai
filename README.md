# DealPilot AI v7

V7 upgrades:
- Manual sold-comp analyzer using average sold price per square foot
- Improved repair estimator with manual override
- 65%, 70%, and 75% buyer rules
- Desired assignment-fee calculation
- Named leads + house photos
- Search/filter/sort and wholesale pipeline stages
- Seller CRM: name, phone, email, motivation, timeline, follow-up
- Seller response assistant
- Cash-buyer database and buy boxes
- Buyer matching and buyer-ready deal packages from v6
- U.S. marketplace concept with clearly labeled demo markets
- Follow-up date stored with each lead
- No property-data API required

Important: no-API mode cannot pull verified public records, live nationwide listings, or verified sold comps. Enter your own comps and verify deal information before making offers or marketing a contractual interest. Photos are stored locally in browser storage.
