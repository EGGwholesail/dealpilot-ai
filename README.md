# DealPilot AI v5 — No API

- RentCast removed
- Number 7-inspired green geometric house logo
- Marketplace-style design inspired by wholesale inventory sites
- Address + Zillow/listing URL first
- Clickable lead cards with full details
- Seller Assistant
- No API keys required

Important: without an outside data source, the app cannot honestly obtain verified comps/public records from only an address and URL. It therefore asks for asking price, square footage, year built, and condition from the listing before producing clearly labeled rough ARV and repair estimates.
